# Voyti API User

REST CRUD endpoints for users, built on [Voyti API](https://github.com/YiiRocks/voyti-api)'s token
authentication and admin middleware, for [Voyti](https://github.com/YiiRocks/voyti), the Yii3
user-management extension.
